**作成日**: 2026-09-09（v2） ／ **起案**: Fujiwara（トラベル事業責任者） ／ **提出先**: 経営戦略会議
**対象**: AIコンシェルジュ（B2C送客・GMV）／ 事前チェックイン（B2B SaaS）／ ボイスコンシェルジュ構想 ／ USDC引換券（CHM PoC）

## I. 結論

**I-1. 現行事業の範囲では、取得必須の許認可はゼロにできる。** v1では「第3種旅行業登録と電気通信事業届出の2つを取る」としたが、一次資料（旅行業法施行要領）を当たり直した結果、Taxi・送迎導線は**「プラットフォーム型」に再設計すれば旅行業に該当しない**（施行要領 第一 4)②）。登録の6ヶ月と100〜150万円、そして最大のボトルネックだった旅行業務取扱管理者の確保が、当面不要になる。

**I-2. ただし迂回には製品上の代償がある。** プラットフォーム型の条件は「UPBONDが契約当事者にならない・代金を収受しない・AIがユーザーに代わって予約を送信しない」の3点。**AIエージェントが予約まで完結させるUXは旅行業そのもの**であり、これを解禁する時点で登録が必要になる。

**I-3. 電気通信事業の届出は「迂回可能だが取る」。** ホテル名義でTwilioを契約しUPBONDはAIソフト提供に徹する、またはAI完結（転送なし）にすれば届出不要にできる。しかし届出は無料・1ヶ月で、Twilio提携の信用にもなるため、取ったほうが安い。

**I-4. USDC引換券は「UPBONDがUSDCに触れない」設計で規制外に置ける。** 電子決済手段等取引業が捕捉するのは売買・交換・その媒介・管理。無償交付と非カストディはその外側にある。ただし金融庁解釈が未確立の領域なので照会は必須。

**I-5. 登録が「必要になる」トリガーを明文化し、事業判断に紐づける。** パッケージ化／エージェント自動予約／自社収納のいずれかを決めた時点で第3種（全国展開の募集型なら第2種）を申請する。それまでの法務コストは v1 の 250〜400万円から **100〜200万円** に下がる。

## V. 論点別の再分析

### 論点A｜旅行業法 — 本当に登録が必要か 🟡（再設計で回避）

**該当／非該当の判定表（施行要領準拠）**

| 行為 | 判定 | 根拠 |
|---|---|---|
| 体験・入場・買物クーポンを単体で扱う | **非該当** | 付随的旅行業務のみは旅行業でない（施行要領 第一 3)②） |
| 運送事業者のために発券業務のみを行う | **非該当** | 法2条1項かっこ書き（施行要領 4)①。航空代理店・回数券販売所の類型） |
| ウェブサイト経由で、取引に働きかけをせず、予約送信前に「旅行者と事業者の取引である」ことを明示 | **非該当** | **施行要領 4)②** |
| AIが提案し、ユーザー自身が予約フォームを送信する | **非該当の余地大（要照会）** | 4)②の延長。「働きかけ」の評価が唯一の論点 |
| AIエージェントがユーザーに代わって予約を送信する | **該当**（取次・代理） | 法2条1項 |
| UPBONDが旅行代金を収受する | **該当** | 施行要領 6)：収納代行は金融機関等に限定 |
| 宿泊＋交通＋体験を組成して販売する | **該当**（企画旅行） | 法2条1項1号 |
| 送客手数料（キックバック）を受領する | 報酬に該当（Q&A問4） | ただし**旅行業務そのものを行っていなければ報酬の有無は問題にならない** |

**現状の評価。** Taxi導線は「AIが提案 → UPBOND内で予約 → UPBOND経由で決済 → レベシェ受領」であり、予約と決済の2点で該当側にいる。**しかし施行要領はウェブ取引の非該当類型を明文で用意している。** 登録を取るより、この類型に当てはめ直すほうが圧倒的に早く安い。

**プラットフォーム型の4条件**

1. 予約入力画面の送信前に「本予約はお客様と○○交通（運送事業者）との契約です」を明示する
2. 予約の送信はユーザー自身が行う。AIは入力補助（候補提示・事前入力）まで。**自動送信しない**
3. 代金は運送事業者に直接着金（Stripe Connect等）。UPBONDは事業者からプラットフォーム利用料を受領する
4. 提携先は運送事業許可を持つ事業者に限定する（論点B）

**旅行業登録が必要になるトリガー（このどれかを決めた時点で申請）**

- パッケージ商品の組成・販売（→ 全国展開の募集型なら第2種、受注型・手配のみなら第3種）
- AIエージェントによる自動予約の解禁
- UPBOND名義での代金収受・決済一元化
- KKday等の旅行業者から国内手配を受託する形態（→ 旅行サービス手配業）

**残るリスク。** AIの「おすすめ」＋成果報酬の組合せが「働きかけ」と評価される可能性。これはグレーゾーン解消制度で観光庁に正面から照会する（原則1ヶ月以内に回答）。回答が出るまでの間も、4条件を満たしていれば行政指導リスクは大きく下がる。

### 論点B｜道路運送法 — 提携先のデューデリジェンス 🔴

変更なし。プラットフォーム型に移行しても、無許可事業者を載せれば白タク幇助の論点は残る。**むしろ「契約当事者は事業者」と明示する以上、事業者の適法性はプラットフォームの信用そのもの。** 許可証の写し取得を提携条件に組み込む。

### 論点C｜電気通信事業法 — 届出は本当に必要か 🟡（迂回可・取る）

**判定表（参入マニュアル追補版準拠）**

| 形態 | 判定 | 根拠 |
|---|---|---|
| 要約付きでスタッフに通話を転送する | **届出必要** | 「転送電話サービス」＝他人の通信の媒介 |
| AIが受電し、内容を変えずにスタッフへチャット伝達する | **届出必要** | 「電話等受付自動代行サービス」＝媒介（文字起こし伝達も含む） |
| AIが応答を生成して完結する（転送・伝達なし） | **第三号事業＝届出不要** | 自己（事業者）と他人（利用者）の通信 |
| ホテル名義でTwilioを契約し、UPBONDはAIソフトを提供する | **届出不要** | UPBONDは電気通信役務を提供していない |

**推奨。** 迂回は2通りあるが、届出は無料・1ヶ月。届出事業者であること自体がTwilio提携とホテル営業の信用になるため、**取る**。ただし届出の有無にかかわらず、通信の秘密（通話内容をAI学習に使うには同意必須）と外部送信規律は第三号事業にも適用される点は変わらない。

### 論点D｜資金決済法 — USDCに触れない設計 🟡（照会必須）

**D-1 ジャパンチケット前払い。** 整理済み（2026-07 水岡メモ）。Taxiには適用できない点は変更なし。ただしプラットフォーム型（事業者直接着金）に移行すれば、**Taxiについては収納代行の論点自体が消える**。

**D-2 USDC引換券。** 電子決済手段等取引業が捕捉する行為は、①電子決済手段の売買・交換 ②その媒介・取次・代理 ③管理 ④資金移動業者の委託を受けた為替取引の媒介。**無償交付（贈与）は売買・交換ではなく、ユーザー自己管理ウォレットへの送付は管理ではない。** 構造上は規制の外側にある。

**触れない設計の3型**

| 型 | 内容 | 評価 |
|---|---|---|
| A. ホテル送付型 | CHMがユーザーの自己管理ウォレットへ直接USDCを送付。UPBONDはウォレット技術とUIのみ提供 | **推奨**。UPBONDは規制行為をしない。CHM側の送付主体化が交渉事項 |
| B. ポイント引換型 | 引換券＝無償ポイント（対価性なし→前払式支払手段非該当）。USDCへの交換はユーザーが登録済業者で行う | 次善。UXが重い |
| C. 自社保有交付型 | UPBONDが保有するUSDCを贈与 | 構造上は非該当だが、海外発行ステーブルコインの国内流通に関する金融庁解釈が未確立。照会なしでは採らない |

9/10のCHM論点整理④で合意した「引換券を先に付与し受取時にコスト確定」は、A型と整合する。**受取時のUSDC送付主体をCHMにできるか**が分水嶺。

### 論点E｜個人情報保護法 — 許認可ではなく設計 🟡

変更なし。目的外利用（委託範囲外の送客）、越境移転（第28条）、GDPR域外適用、要配慮情報。プラットフォーム型に移行すると**予約情報が運送事業者へ直接渡る**ため、第三者提供の同意文言を予約フォームに組み込む必要が新たに生じる。

### 論点F｜旅館業法 — 攻めの材料 🟢

変更なし。事前チェックインの適法性チェックリストは、来期提案書（共立・ルートイン・東急ステイ）の差別化材料として作る。

### 論点G｜景表法・薬機法・特商法 — AI生成表現 🟡

変更なし。プラットフォーム型では**「契約当事者は○○交通」の表示が特商法上の販売者表示も兼ねる**ため、表示設計は論点Aと同時に行う。

## VII. 時間軸

### Phase 0：再設計着手（9/9 〜 9/30・3週間）
- Taxi・送迎導線の**プラットフォーム型改修に着手**（契約当事者明示・ユーザー送信・事業者直接着金）。
- 増田パートナーズへ2件のスポット照会（プラットフォーム型の該当性／USDC A型）。
- 運送系提携先から許可証を回収。
- 9/10 CHM論点整理④で「受取時のUSDC送付主体＝CHM」を提案。

### Phase 1：リリースと照会（10月 〜 11月・2ヶ月）
- **プラットフォーム型をリリース**（11月）。GMVへの影響を計測。
- **グレーゾーン解消制度**の照会書を観光庁へ提出。
- **電気通信事業の届出**を完了。
- プライバシーポリシー・同意フローの改訂、AI表現ガードレール実装。
- 事前チェックイン適法性チェックリストを来期提案書に同梱。

### Phase 2：回答受領と事業判断（12月 〜 2027年2月・3ヶ月）
- グレーゾーン回答を受領し、4条件を確定または微修正。
- **パッケージ化・エージェント自動予約を FY2027 にやるかを事業判断** → やるなら第3種／第2種の登録を申請（ここから6ヶ月）。

### Phase 3：拡大（2027年3月 〜）
- 登録が必要と判断した場合：申請 → 2027年Q3解禁。
- 不要と判断した場合：プラットフォーム型のまま送客商材を拡大。
